# 焦点流程实验页 · Focus Flow Lab

条件表单里，控件会随开关状态出现/消失。仅检查默认状态下的 Tab 顺序无法发现这样一类问题：
键盘用户沿着某串按键进入一个**从入口可达、却再也无法抵达目标**的状态（焦点陷阱）。

本项目把“焦点节点 × 开关位集”当作显式状态空间，对其做搜索：

- **最短按键序列**：从初始状态（入口节点、所有开关为关）到目标节点的最少按键；
- **最短陷阱前缀**：走到一个“可达但目标从此不可达”状态的最少按键；
- 同长度时按 **Tab → Shift+Tab → 激活** 的顺序裁决；
- **逐键回放**见证序列，并高亮所有失效边（含“激活翻转开关后目标节点消失”）。

## 模型

状态为 `(focus, bits)`：

- `focus`：当前持有焦点的节点下标；只有可见节点能承载焦点。
- `bits`：布尔开关位集，第 k 位为 1 表示开关 k 为“开”。初始 `bits = 0`。

每个节点定义：

- `visible`：可见条件，是若干 `{ switch, on }` 的**合取**；
- `tab` / `shiftTab` / `activate`：三个动作，各给出
  - `target`：动作后的焦点节点（`null` 表示停留自身，缺省字段表示未定义该动作）；
  - `toggle`：仅激活常用，翻转某开关。

**动作合法性（关键语义）**：激活的翻转先发生，再判定目标在新位集下是否可见。
因此“关掉支撑当前节点可见性的开关”会产生一条 `target-hidden-after-toggle` 失效边——
该按键走不通，即使目标就是当前焦点节点本身。

## 搜索算法（`src/lib/focus.ts`）

1. **前向 BFS**：从初始状态按 `Tab、Shift+Tab、激活` 的固定顺序扩展，首个出队的目标状态
   给出“最短 + 裁决顺序”的路径；BFS 跑完整张可达子图，供计数与失效边枚举。
2. **必胜状态反向固定点**：所有“目标节点”状态为胜，一个状态只要存在合法动作通向胜状态即为胜，
   迭代至不动点（用逆邻接表传播）。
3. **陷阱 BFS**：从初始状态再做一次 BFS，首个落入“非必胜”集合的状态其前缀即最短陷阱；
   若初始状态本身非必胜，陷阱为 `[]`。
4. **失效边枚举**：可达范围内每个状态的每个动作，若 `edgeStatus` 判定为隐藏/未定义，
   记录供界面高亮。

规模上限 40 节点 × 2^8 位集 = 10240 状态，全程毫秒级。

## 导入格式

```jsonc
{
  "switches": [{ "id": 0, "label": "电源" }],   // 0..8 个，id ∈ 0..7
  "nodes": [                                      // 2..40 个，id 唯一
    {
      "id": "A",
      "label": "入口表单",
      "visible": [{ "switch": 0, "on": true }],  // 合取；省略=始终可见
      "tab": { "target": "B" },
      "shiftTab": { "target": "C" },
      "activate": { "target": null, "toggle": 0 } // 停留自身并翻转开关 0
    }
  ],
  "entry": "A",   // 入口在 bits=0 时必须可见，且与目标不同
  "target": "T"
}
```

校验失败（数量越界、id 重复、悬空引用、入口/目标相同、入口初始不可见、JSON 解析错误等）
只会显示错误，**不会覆盖当前图**；可一键“恢复上一版图”。

## 测试

- `test/reference.ts`：与产品代码**独立**的参考实现（Map/Set + 迭代不动点，
  只共用转移原语 `edgeStatus`），用于对拍；
- `test/focus.test.ts`：
  - 示例图断言最短路径 `激活 → Tab → Tab`、最短陷阱 `Shift+Tab`；
  - 专门覆盖**切换后节点消失**（`target-hidden-after-toggle`）与切换后节点新出现；
  - 不可达目标、初始即困、同长度裁决顺序；
  - 各类非法导入拒绝；
  - **400 张随机合法小状态图**对拍路径/陷阱/可达/必胜集合；
  - 最大规模（10240 状态）性能与对拍；
- `test/ssr.test.ts`：无浏览器，以 Svelte SSR 编译渲染 App/NodeCard，
  断言页面呈现搜索结论与失效边（该冒烟还顺带守护实例初始化顺序）。
